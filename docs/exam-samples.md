# 공식 수능 예시문항

2026-10-28에 평가원 수능 홈페이지의 수험자료·기출문제, 평가원 보도자료,
교육부 보도자료, EBSi 원문과 실제 PDF를 확인했다. 현재 공식 원본을 확인한 대상
학년도는 **2017·2018·2022·2028학년도**이다. 확인하지 못한 학년도의 URL을
추정해서 넣지 않는다. 2005·2014학년도 예비평가/예비시행과 일반 모의평가는
별도 시행 시험이므로 예시문항으로 바꾸거나 다시 수록하지 않는다. 현행 공식
게시판의 제목·본문 검색에서는 2005·2014학년도 별도 예시문항 원본을 확인하지
못했다. 이것을 과거에 해당 자료가 존재하지 않았다는 뜻으로 해석하면 안 된다.

| 대상 학년도 | 실제 내용과 공개분 | 과목 선택 |
|---|---|---|
| 2017학년도 | 2014-04-11 공개 한국사 필수 도입 안내. 유형별 문제·정답·학습 안내가 한 PDF | 고3·N수 → 영어·한국사 → 한국사 |
| 2018학년도 | 영어 절대평가 학습 안내의 유형별 예시·정답. 기존 기출 활용 포함 | 고3·N수 → 영어·한국사 → 영어 |
| 2022학년도 | 국어·수학·성공적인 직업생활. 2020년 안내서와 2020-07-02 문제지·정답표 | 고3·N수 → 국어 → 국어 / 수학 → 수학 / 직업탐구 → 성공적인 직업 생활 |
| 2028학년도 | 2024-09-26 통합사회·통합과학 초기 공개분(각 12문항) | 고3·N수 → 사회탐구 → 통합사회 / 과학탐구 → 통합과학 |
| 2028학년도 | 2025-04-15 국어·수학·통합사회·통합과학 문제지·정답표와 안내서 | 고3·N수 → 해당 영역 → 국어·수학·통합사회·통합과학 |
| 2028학년도 | 제2외국어/한문 변경 안내에 실린 9과목의 예시·정답(한 PDF) | 고3·N수 → 제2외국어·한문 → Ⅰ이 없는 새 과목명 |

출제 기관 줄 오른쪽의 **예시문항** 탭에서 과목군·과목을 고른다.
일반 **전체·평가원·교육청**과 예시문항의 과목 목록은 별개다. 일반 탭에는 시행된
기출만, 예시문항 탭에는 예시 자료가 있는 과목만 표시한다. 두 범주의 마지막
선택을 각각 유지하며, 예전 예시문항 전용 과목의 공유 주소도 새 탭으로 연결한다.
자료는 해당 학년도 필터에서도 보인다. 등록일은 아는 경우에만 표시하며 시행일이
아니다. `2028학년도` / `28`처럼 대상 학년도를 사용한다. 기관별로 표기 규칙을
나누지 않는다. 제2외국어/한문 안내와 영어 안내의 정확한 등록일은 확인되지 않아
`published: null`로 둔다. PDF 식별자는 각각 `PIM 2026-31`, `CAT 2016-19`이며,
이 발행 연도를 학년도로 사용하지 않는다.

## 원본과 중복

- [평가원 수험자료 목록](https://www.suneung.re.kr/sub/info.do?m=0401&s=suneung):
  현재 연결된 안내서 전부를 검토했다. 일반 2027학년도 학습·Q&A 안내는 별도
  예시문항 공개분으로 세지 않는다.
- [평가원 2028학년도 예시문항 게시판](https://www.suneung.re.kr/boardCnts/list.do?boardID=1500237&m=0403&s=suneung):
  네 영역의 실제 별도 문제지와 정답표를 내려받아 본문과 정답표 영역을 확인했다.
- [평가원 2022학년도 문제지 탑재 보도자료](https://www.kice.re.kr/boardCnts/view.do?boardID=10024&boardSeq=5050074&lev=0&m=050102&s=kice&statusYN=W):
  안내서 예시문항을 문제지 형식으로 **재편집**했다고 밝힌다. 5월 안내서와 7월
  문제지를 별도 문항 세트로 중복 등록하지 않고 동일 항목에서 제공한다. 국어
  문제지에는 공통+화법과 작문+언어와 매체, 수학에는 공통+확률과 통계+미적분+기하가
  함께 있다. 별도 선택지 파일인 것처럼 나누지 않는다.
- [교육부 2024년 공개](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=101085&lev=0):
  실제 첨부 PDF는 75쪽이고 평가원 자료실 판본은 79쪽이다. 같은 초기 공개분의
  제공 형식이므로 하나의 항목으로 묶는다. 정답·문항 안내가 포함된 한 PDF를
  별도 문제·정답·해설 파일이라고 표시하지 않는다.
- [교육부 2025년 공개](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=103113&lev=0):
  지정된 `[별첨] 2028학년도 대학수학능력시험 예시문항 안내.pdf`는 실제 154쪽이다.
  문제지·정답표 부록을 포함한다. 2024년 초기 공개분과 다른 공개분으로 표시한다.
  평가원 자료실 안내서도 확인했으며 본문 텍스트는 같고 뒷표지 연락처·ISBN
  텍스트가 추가된 판본이다. 별도 회차로 세지 않는다.
- [EBSi 예시문항 분석자료집](https://www.ebsi.co.kr/ebs/ent/enta/retrieveMyGlUnivLearnEntAnalysisView.ebs?datNo=620487):
  페이지의 실제 다운로드 함수와 첨부 목록에서 네 영역의 원본을 확인했다.
  PDF는 각각 18·9·11·15쪽이며 **주요 문항** 해설·분석이다. 전체 문항의 해설로
  표시하지 않는다. 평가원의 문항·교수학습 안내도 완전한 해설지라고 부르지 않는다.

검토한 파일의 실제 URL·쪽수·SHA-256은 [sample-sources.json](sample-sources.json)에
남겼다. 원본 PDF는 저장소에 저장하거나 재배포하지 않는다. 같은 URL을 여러
과목에서 연결할 수 있으며 이것은 새 공개분을 뜻하지 않는다. 문항이 일부 재사용될
수 있으므로 공개분의 구분을 문항 전체의 신규성으로 해석하면 안 된다.

## 구현과 검증

- 기준 자료는 `index.html`의 `samples` JSON. EBSi 갱신 대상 `payload`와 분리해
  갱신량·활성 과목 검사와 기존 기록을 유지한다. `data/samples.json`, 과목별 JSON의
  `samples`, 과목 페이지는 기존 생성기에서 내보낸다. `papers`, 원본 날짜·주소·키는
  그대로다. 예시문항에는 시행일·시행 연도·기록 키를 만들지 않는다.
- `900001`~`900004`, `900011`~`900019`는 이 목록의 지역 식별자이며 EBSi 과목
  코드라고 주장하지 않는다. 2028학년도 국어·수학은 공통 영역, 통합사회는 사회탐구,
  통합과학은 과학탐구에 두며 예전 선택과목에 넣지 않는다.
- 웹은 공식 링크로 이동한다. Android 10.8부터는 확인된 24개 공식 PDF를 기존
  앱 PDF 뷰어로 연다. `openSamplePaper` 전용 브리지는 `PaperSources.java`의 정확한
  URL만 허용하며, 다른 주소로의 리디렉션을 차단한다. 평가원·교육부 도메인 전체를
  허용하지 않는다. ‘공식 출처’ 웹페이지는 브라우저로 연다. 구형 앱에서는 기존의
  외부 링크가 유지되므로 앱 업데이트가 필요하다. 시행일·기록 키를 만들거나 기존
  타이머·OMR·정답 키를 붙이지 않는다.
- `python3 tools/build_sample_sources.py`가 검증된 `samples` 목록에서 Android의
  정확한 주소 목록과 대상 학년도를 생성한다. `--check`와 `test_samples`가 일치를
  확인한다. 새 예시 PDF 주소를 추가할 때는 이 생성기와 APK 판올림도 함께 처리한다.
  Android HTTP 사용자 에이전트로 24개 주소 모두 HTTP 200과 PDF 본문을 확인했고,
  새 브리지·구형 앱 fallback·정확한 URL 및 리디렉션 제한을 검사한다. 실기기 PDF
  렌더링 검증으로 보고하지 않는다.
- `tests/test_samples.py`는 대상 학년도/짧은 표기, 영역, 별도 공개분, 실제 원본 URL
  형태, JSON과 화면 일치, 기존 데이터 보존·갱신 후 보존, 네이티브 브리지 호출 격리를
  확인한다. 원본에 대한 네트워크 검증은 파일 지문 기록과 구분한다.
- 생성 순서: `build_api.py` → `build_pages.py` → `check_csp.py --fix` →
  `build_fonts.py`. 실제 문구에 필요한 글자를 생성하며 APK를 피하기 위해 문구를
  바꾸지 않는다. 10.7에서 “해설·분석”의 글꼴을 갱신했고, Android 10.8
  (versionCode 99)에서 공식 예시 PDF의 앱 뷰어 연결을 추가한다.
  전체 회귀 검사와 기존 GitHub Pages 배포 경로를 사용한다.
